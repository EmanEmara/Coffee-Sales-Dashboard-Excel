#Coffee Sales Dashboard
Overview

This project is an interactive Excel dashboard created to analyze coffee sales performance across customers, countries, product sizes, roast types, and time periods.
Tools Used

    Microsoft Excel
    Pivot Tables
    Pivot Charts
    Slicers
    Timeline Filters
    INDEX/MATCH

Features

    Sales trends over time
    Sales by country
    Top 5 customers
    Roast type filtering
    Package size filtering
    Loyalty card filtering
    Dynamic dashboard interaction using slicers


Skills Demonstrated

    Data Analysis
    Data Visualization
    Dashboard Design
    Business Reporting
    Excel Functions
